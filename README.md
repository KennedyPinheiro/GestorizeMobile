# GestorizeMobile


## Descrição do Projeto
O GestorizeMobile é um aplicativo mobile desenvolvido para auxiliar pequenas e médias empresas no gerenciamento de processos administrativos essenciais. 
A aplicação permite organizar e controlar informações relacionadas a funcionários, clientes, produtos, fornecedores e orçamentos de forma centralizada.
O sistema é composto por uma API backend desenvolvida em Laravel, responsável pelas regras de negócio e acesso aos dados, e um aplicativo mobile desenvolvido em React Native utilizando Expo e TypeScript, 
responsável pela interface e interação com o usuário.

O banco de dados utilizado é MySQL, garantindo persistência e integridade das informações.

## Funcionalidades
 - Gestão de Funcionários
   
Permite o cadastro, atualização e visualização de informações dos colaboradores da empresa.

- Gerenciamento de Clientes

Possibilita registrar clientes, consultar seus dados e acompanhar o histórico de orçamentos vinculados.

- Controle de Produtos

Permite cadastrar produtos ou serviços, atualizar preços e associar fornecedores aos itens cadastrados.

- Criação de Orçamentos

Permite gerar orçamentos personalizados para clientes, editar informações e armazenar registros para consulta futura.

- Autenticação
  
O sistema utiliza autenticação baseada em JWT, garantindo segurança no acesso às rotas da API.

## Tecnologias Utilizadas
### Backend

- Laravel
- PHP
- MySQL
- JWT Authentication

### Mobile

- React Native
- Expo
- TypeScript
